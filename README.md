# Bekasbagus - Platform Jual Beli Barang Second (Marketplace)

Tugas Perkuliahan Bab 6 - React Dasar.

## Fitur
- Katalog Produk dengan State Array (`.map`)
- Form Tambah Barang (Controlled Component)
- Conditional Rendering (Tampilan jika data kosong)
- Halaman Panduan COD
- Desain responsif menggunakan Tailwind CSS

## Cara Menjalankan
1. `npm install`
2. `npm run dev`
3. Buka `http://localhost:5173`
